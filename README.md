# 시니어 알고리즘 클리너

사용자의 YouTube 구독 채널을 분석해 건강정보 리스크와 공장형 생산 가능성을 근거와 함께 보여주고, 사용자가 선택한 채널을 한 번에 구독 해제하는 웹 애플리케이션입니다.

이 디렉터리는 기존 `openai-workshop`의 임시 데모 구현과 분리한 신규 구현 공간입니다. 기존 데모 코드는 설계 기준이나 재사용 기반으로 삼지 않습니다. 아래 문서와 앞으로 작성할 기능별 SDD spec을 기준으로 새로 구현합니다.

## 기준 문서

- [PRD](./docs/PRD.md): 제품 범위, 판정 원칙, 사용자 흐름, 완료 조건
- [분석 워크플로](./docs/ANALYSIS_WORKFLOW.md): 구독 수집, 영상 선정, LLM-as-judge, 점수와 구독 해제 흐름
- [API 데이터 상세](./docs/API_DATA_DETAILS.md): YouTube Data API의 데이터 계약과 quota 제약
- [문제 근거](./docs/PROBLEM_RESEARCH.md): 시니어 건강 영상 문제의 기사·조사·연구
- [워크숍 맥락](./docs/WORKSHOP.md): 행사 목적과 평가 기준
- [SDD spec 안내](./docs/specs/README.md): 기능별 명세 작성 규칙과 예정 구조

## 상태

현재는 제품 문서와 SDD 기준만 있으며 본 애플리케이션 구현은 시작하지 않았습니다. 한국 리전에서 사용할 수 없는 Google Data Portability smoke 구현은 제거했습니다. 기존 `openai-workshop` 데모 코드도 설계 기준이나 재사용 기반으로 삼지 않습니다.

확정 범위는 다음과 같습니다.

- 입력: YouTube 구독 목록만 사용
- 분석 영상: 채널별 최신 2개와 인기 3개
- 리스크: LLM-as-judge가 고정 루브릭을 직접 채점
- 공장형 가능성: YouTube 메타데이터를 코드로 계산
- 결과: 채널별 두 점수와 위험 판단 이유
- 액션: 사용자가 체크하고 최종 확인한 채널만 일괄 구독 해제
- 제외: 최근 시청, Data Portability, 좋아요·싫어요, 자동 액션, 추출·재검증 파이프라인
