# 유튜브 건강검진 — 구현 Handoff

- 기준일: 2026-09-04
- 상태: 분석·표시 계약 확정, 바로 구현 가능
- 우선순위: 이 문서가 다른 제품 문서보다 우선한다.

## 제품과 사용자 흐름

사용자의 YouTube 구독 채널을 분석해 콘텐츠 리스크와 공장형 가능성을 합산한 위험도와 쉬운 한 줄
이유를 보여준다. 사용자가 직접 고른 채널만 재확인한 뒤 구독 해제한다.

```text
OAuth → 구독·채널·업로드 수집 → 규칙 기반 건강 후보 선별
→ 고유 영상 최대 5개 선정 → Gemini 증거 추출 → Gemini 콘텐츠 채점
→ 결정적 공장형 계산 → Gemini 썸네일 비교 → 채널 합산·정렬
→ 사용자 선택 → 최종 확인 → 선택한 subscriptionId만 구독 해제
```

## 표본

- 최신 공개 영상 2개.
- 현재 시점 기준 최근 1년에 게시된 공개 영상 중 현재 누적 조회 수 상위 3개.
- 최신 영상과 겹치면 건너뛰고 다음 인기 영상으로 보충해 가능하면 고유 5개를 만든다.
- 영상 형식과 건강 여부로 표본을 다시 나누거나 제외하지 않는다.
- 썸네일은 별도로 최신 공개 영상 3개를 한 요청에 함께 비교한다.
- 상세 메타데이터는 `videos.list(part=snippet,contentDetails,statistics,status)`로 보강한다.
  `containsSyntheticMedia` 부재는 `unknown`이며 `false`로 바꾸지 않는다.

## 콘텐츠 리스크 0..50

각 영상은 두 단계로 처리한다.

1. `evidence-extraction-v1`: 공개 YouTube URL 1개를 Gemini에 전달하고 건강 주장, 행동 지시,
   상업 신호, 출처 신호, 발화자 정보, 근거 문구·타임스탬프와 한계를 JSON으로 추출한다. 점수는
   만들지 않는다.
2. `content-risk-v1`: 증거 JSON과 영상·채널 제목/설명을 별도 텍스트 요청으로 전달해 채점한다.
   URL을 다시 주거나 외부 링크를 따라가지 않는다.

| 축 | 범위 | 핵심 기준 |
|---|---:|---|
| 출처 불명확 | 0..30 | 중요한 건강 주장의 출처·발화자·근거 연결을 제공 내용에서 추적할 수 없는 정도 |
| 치료·복약 변경 유도 | 0..10 | 복약·치료 중단/변경, 진료 회피, 대체요법 전환을 유도하는 정도 |
| 구매 유도 | 0..10 | 건강 효과·불안이 특정 상품, 가격, URL, 주문 방법, 긴급성에 연결되는 정도 |

비건강 영상도 같은 기준으로 평가하며 관찰 신호가 없으면 0점이다. 채널 콘텐츠 리스크는 성공한
결과만 사용해 `round(최고 영상 점수 × 0.5 + 영상 평균 × 0.5)`로 계산한다. 1개 이상 성공하면
계산하고 5개 모두 실패하면 계산 불가다.

## 공장형 가능성 0..50

### 업로드 패턴 0..10

최근 90일 공개 업로드에서 모든 5개 연속 창을 평가하고 최고 점수 창을 쓴다.

- `cadenceHours = (첫 영상과 다섯째 영상 사이 시간) / 4`
- 속도 0..20: `≤3h 20`, `≤6h 18`, `≤12h 15`, `≤24h 12`, `≤48h 8`, `≤72h 4`,
  `>72h 0`.
- 규칙성 0..10: 네 간격의 `median(abs(gap - medianGap)) / medianGap`이 `≤10% 10`,
  `≤25% 7`, `≤50% 4`, 그 외 0. cadence가 72시간을 넘으면 규칙성도 0이다.
- 최근 90일 영상이 5개 미만이면 계산 불가다.
- 아래 속도·규칙성 합계 0..30은 측정 원점수다. 최종 공장형 기여도는 `round(원점수 / 3)`으로
  0..10에 맞춘다.

### 합성 공개 표시 0..10

콘텐츠 표본 5개 중 `containsSyntheticMedia=true` 1개당 2점, 최대 10점이다. `unknown`과 false는
0점이나 서로 다른 상태로 저장한다. 콘텐츠 위험 근거로는 쓰지 않는다.

### 썸네일 유사도 0..30

최신 공개 영상 3개 썸네일을 Gemini 한 요청에 함께 보내 구성, 텍스트 배치, 색상, 아트스타일을
통합 평가한다. LLM 측정값 0은 공통 패턴 없음, 5~6은 변형이 보이는 공통 템플릿, 9는 요소만 치환한 같은
템플릿, 10은 사실상 동일한 템플릿이다. 한 쌍만 비슷하면 최대 6점이며 7점 이상은 세 장 모두의
공통 패턴이 필요하다. 이 0..10 측정값을 3배해 공장형 점수 0..30으로 반영한다. 썸네일 최종
실패 시 공장형과 합산 점수는 계산 불가다.

## 실행·실패 계약

전역 단계 장벽을 둔다: 모든 영상 증거 추출 → 모든 콘텐츠 채점 → 모든 채널 썸네일 비교. 각
단계의 동시 실행 수는 `GEMINI_JUDGE_CONCURRENCY`(확정값 8)를 넘지 않는다. 채널 8개와 영상
5개라면 40 + 40 + 8 = 88회 호출이다. 시간 초과, 429, 5xx, 잘못된 JSON은 최초 포함 최대 3회
시도한다. 실패 영상을 0점으로 넣지 않는다.

## 합산·표시

```text
합산 위험도 = 콘텐츠 리스크(0..50) + 공장형 가능성(0..50)
```

| 합산 위험도 | 표시 |
|---:|---|
| 0..20 | 정상 |
| 21..60 | 경고 |
| 61..100 | 위험 |

분석 불가 채널을 먼저, 나머지는 합산 위험도 내림차순으로 정렬한다. 카드에는 합산 점수와 두
하위 점수, 한 줄 이유만 크게 표시한다. 한 줄 이유는 여섯 실제 기여도 중 큰 두 개를 코드가
결정적으로 고른다. 동률 우선순위는 치료·복약 변경 → 구매 → 출처 → 업로드 → 합성 표시 →
썸네일이다. 전부 0이면 `분석한 영상에서 뚜렷한 위험 신호를 찾지 못했습니다.`를 표시한다.

## 불변조건

- 체크박스 기본 미선택, 자동 선택·자동 구독 해제 금지.
- 최종 승인 뒤 현재 세션의 선택한 `subscriptionId`만 삭제.
- OAuth 토큰, API 키, 구독 ID를 클라이언트나 LLM에 전달하지 않음.
- 스크래핑, 비공식 자막, 영상 다운로드, YouTube 화면 자동화 금지.
- 결과 보관은 `ANALYSIS_TTL_HOURS`를 따른다.
