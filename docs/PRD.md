# 시니어 알고리즘 클리너 — PRD

- 기준일: 2026-09-04
- 대상 도메인: YouTube 건강 콘텐츠
- 제품 상태: 구현 전 확정안

## 1. 한 줄 정의

사용자의 YouTube 구독 채널을 분석해 건강정보 리스크와 공장형 생산 가능성을 근거와 함께 보여주고, 사용자가 선택한 채널을 한 번에 구독 해제하는 웹앱이다.

## 2. 문제

시니어와 가족은 구독 중인 건강 채널 가운데 과장된 의료 주장이나 반복·대량생산 패턴이 있는 채널을 일일이 확인하기 어렵다. 구독 목록에는 채널명만 보일 뿐, 어떤 채널을 왜 다시 살펴야 하는지 비교 가능한 근거가 없다.

## 3. 목표

1. Google 계정으로 연결해 사용자의 YouTube 구독 목록을 자동 수집한다.
2. 건강 관련 채널만 분석 대상으로 분류한다.
3. 채널 메타데이터로 `공장형 점수`를 계산한다.
4. 채널마다 최신 영상 2개와 인기 영상 3개를 LLM-as-judge로 평가해 `리스크 점수`를 계산한다.
5. 두 점수와 판단 이유를 채널별로 보여준다.
6. 사용자가 체크박스로 선택한 채널만 최종 확인 후 일괄 구독 해제한다.

## 4. 비목표

- Google Data Portability API 및 최근 시청 기록
- Google Takeout 파일 가져오기
- 영상 좋아요·싫어요 처리
- 자동 구독 해제
- YouTube 홈의 `관심 없음`, `채널 추천 안 함` 조작
- AI 생성 여부 판별
- 채널이나 영상을 법적 의미의 허위·불법 콘텐츠로 확정
- LLM 판단을 별도 LLM 또는 규칙 엔진으로 재검증

## 5. 사용자 흐름

```text
Google 계정 연결
→ YouTube 구독 목록 수집
→ 채널 공개 메타데이터와 업로드 목록 수집
→ 건강 관련 채널 후보 선별
→ 최신 영상 2개와 인기 영상 3개 선택
→ LLM-as-judge가 영상별 루브릭과 리스크 점수 생성
→ 코드가 채널 리스크 점수와 공장형 점수 집계
→ 위험 채널 목록과 판단 이유 표시
→ 사용자가 구독 해제할 채널 체크
→ 선택 대상과 개수 최종 확인
→ 선택한 채널만 일괄 구독 해제
→ 성공·실패 결과 표시
```

## 6. 판정 결과

채널마다 서로 다른 의미의 두 점수를 표시한다.

| 점수 | 범위 | 의미 |
|---|---:|---|
| 리스크 점수 | 0~100 | 대표 영상의 건강정보 내용이 오해 또는 위해 행동을 유발할 가능성에 대한 LLM 평가 |
| 공장형 점수 | 0~100 | 채널이 짧은 기간에 유사한 영상을 반복·대량생산하는 정도에 대한 메타데이터 계산 |

두 점수를 하나로 합친 종합점수는 만들지 않는다. 공장형이라는 사실만으로 건강정보가 위험하다고 단정할 수 없기 때문이다.

목록 정렬 기본값은 `리스크 점수 내림차순 → 공장형 점수 내림차순`이다.

## 7. 분석 영상 표본

채널마다 다음 영상을 평가한다.

| 표본 | 개수 | 선택 방법 |
|---|---:|---|
| 최신 영상 | 2개 | 업로드 재생목록의 최신 공개 영상 |
| 인기 영상 | 3개 | 채널 동영상 검색 결과를 조회 수 내림차순으로 정렬 |

- 최신·인기 목록이 겹치면 `videoId`로 중복을 제거한다.
- Shorts, 라이브 다시보기와 일반 영상을 모두 포함하되 영상 유형을 결과에 표시한다.
- 삭제·비공개·지역 제한·LLM 처리 불가 영상은 평가에서 제외하고 사유를 표시한다.
- 평가 가능한 영상이 3개 미만이면 `표본 부족`을 표시한다.
- 인기 영상 조회 quota가 부족하면 인기 영상 없이 최신 영상만 평가하고 `인기 영상 미수집`을 표시한다.

## 8. LLM-as-judge 리스크 루브릭

LLM은 영상 콘텐츠와 제목·설명·채널 정보를 보고 다음 네 항목을 직접 채점한다.

| 항목 | 배점 | 판단 질문 |
|---|---:|---|
| 의료행동 위험 | 40 | 약·진료·검사를 중단하거나 검증되지 않은 방법으로 대체하도록 유도하는가? |
| 치료효과 과장 | 20 | 완치, 100%, 무조건, 누구나 효과 등 결과를 과도하게 확정하는가? |
| 근거 품질 | 20 | 핵심 주장에 식별 가능한 연구·기관·전문가 근거가 있는가? 근거가 없거나 체험담만 있으면 높은 위험 점수를 부여한다. |
| 기만적 설득·판매 | 20 | 공포·긴급성·음모론·불명확한 권위를 사용하거나 치료 주장과 제품 판매를 결합하는가? |

```text
영상 리스크 점수
= 의료행동 위험
+ 치료효과 과장
+ 근거 품질 위험
+ 기만적 설득·판매 위험
```

각 항목은 정수로 반환하고 항목별 최대값과 총점 100을 넘을 수 없다. LLM은 점수와 함께 다음을 반환한다.

- 건강 관련 영상 여부
- 항목별 점수
- 핵심 판단 이유 최대 3개
- 이유를 뒷받침하는 발언 또는 화면 문구
- 가능한 경우 타임스탬프
- 데이터가 부족한 경우의 한계

LLM 출력을 다른 모델이나 규칙 엔진으로 재검증하지 않는다. 대신 모델명, 프롬프트 버전, 평가 시각을 저장해 결과의 재현 조건을 남긴다.

## 9. 채널 리스크 점수

평가 가능한 고유 영상의 점수로 결정적으로 집계한다.

```text
채널 리스크 점수
= 최고 영상 리스크 점수 × 0.6
+ 평가 영상 평균 리스크 점수 × 0.4
```

한 영상의 심각한 문제를 단순 평균이 지나치게 희석하지 않으면서, 나머지 영상 표본의 경향도 반영하기 위한 공식이다. 소수점 첫째 자리에서 반올림한다.

| 채널 리스크 점수 | 화면 그룹 |
|---:|---|
| 70~100 | 위험도 높음 |
| 40~69 | 확인 필요 |
| 0~39 | 뚜렷한 위험 신호 없음 |
| 계산 불가 | 표본 부족 |

등급은 목록을 나누기 위한 표시일 뿐 자동 액션을 발생시키지 않는다.

## 10. 공장형 점수

LLM이 아니라 YouTube 메타데이터를 코드로 계산한다.

| 항목 | 배점 | 계산 데이터 |
|---|---:|---|
| 최근 업로드량 | 25 | 최근 30일 공개 영상 수 |
| 업로드 간격 | 20 | 최근 영상 사이 시간 간격의 중앙값과 일일 최대 업로드 수 |
| 제목 반복 | 25 | 정규화한 제목의 완전 중복 및 템플릿 유사도 |
| 설명 반복 | 15 | 링크·공통 안내문을 제거한 설명 본문의 유사도 |
| 운영 기간 대비 생산량 | 15 | 공개 영상 수를 채널 운영 개월 수로 나눈 값 |

정확한 산식과 임계값은 [분석 워크플로우](./ANALYSIS_WORKFLOW.md)에 고정한다. 구독자 수, 조회 수, 채널 개설 연도 자체는 점수에 넣지 않는다.

## 11. 결과 카드

각 채널 카드에는 다음을 표시한다.

- 체크박스
- 채널명과 썸네일
- 구독 시작일
- 리스크 점수와 등급
- 공장형 점수
- 평가 영상 수와 최신·인기 구성
- 위험하다고 판단한 핵심 이유 최대 3개
- 해당 이유가 발견된 영상 제목
- 가능한 경우 발언·화면 문구와 타임스탬프 링크
- 표본·LLM·API 한계

체크박스는 기본적으로 선택하지 않는다.

## 12. 구독 해제

1. 사용자가 채널 체크박스를 선택한다.
2. 하단 고정 버튼에 `선택한 N개 채널 구독 해제`를 표시한다.
3. 확인 화면에서 채널명과 개수를 다시 보여준다.
4. 사용자가 최종 확인하면 `subscriptions.delete`를 호출한다.
5. 채널별 성공·실패를 분리해 표시한다.
6. 실패한 채널만 다시 시도할 수 있게 한다.

분석 완료, 높은 점수, 특정 표현 발견만으로는 구독을 자동 해제하지 않는다.

## 13. 성공 조건

1. 실제 계정의 구독 목록을 페이지 끝까지 가져온다.
2. 각 건강 후보 채널에 대해 최신 2개와 인기 3개를 최대한 확보한다.
3. LLM이 영상별 루브릭 점수와 이유를 구조화된 형식으로 반환한다.
4. 채널 리스크와 공장형 점수를 분리해 표시한다.
5. 사용자가 선택한 채널만 최종 확인 후 구독 해제된다.
6. 실행 결과에서 성공·실패 채널을 확인할 수 있다.
7. 최근 시청, Data Portability, 좋아요·싫어요, 자동 액션이 제품에 노출되지 않는다.
