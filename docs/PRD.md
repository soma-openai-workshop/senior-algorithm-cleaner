# 유튜브 건강검진 PRD

## 목표

YouTube 구독 목록에서 건강정보 후보 채널을 찾아 영상 내용과 제작 패턴을 분석하고, 사용자가
구독 유지 여부를 스스로 결정할 수 있는 큰 글씨의 결과 목록을 제공한다.

## 성공 경험

1. 사용자는 Google OAuth로 자신의 구독 목록만 읽는다.
2. 앱은 규칙으로 건강정보 후보를 넓게 선별한다.
3. 후보마다 콘텐츠 리스크 0..50, 공장형 가능성 0..50, 합산 위험도 0..100과 쉬운 한 줄 이유를
   보여준다.
4. 사용자는 기본 미선택 체크박스로 채널을 고르고 확인 화면을 거친다.
5. 최종 승인한 `subscriptionId`만 삭제하고 채널별 결과를 보여준다.

## 기능 요구사항

- `FR-COLLECT`: `subscriptions.list`, `channels.list`, uploads 재생목록을 페이지 끝까지 수집한다.
- `FR-CLASSIFY`: 채널명·설명과 최신 영상 제목·설명에 버전된 룰을 적용해 건강 후보를 선별한다.
- `FR-SAMPLE`: 최신 2개와 최근 1년 누적 조회 수 상위 3개를 중복 없이 최대 5개 선정한다.
- `FR-DETAIL`: `videos.list`로 영상 정보, 조회 수, 썸네일, 합성 공개 표시를 보강한다.
- `FR-EVIDENCE`: Gemini가 공개 YouTube URL 한 개에서 루브릭 관련 관찰 근거 JSON만 추출한다.
- `FR-JUDGE`: 별도 Gemini 요청이 증거 JSON과 제공 메타데이터로 콘텐츠 3축을 채점한다.
- `FR-FACTORY`: 최근 90일 업로드 패턴과 합성 공개 표시를 규칙으로, 최신 3개 썸네일 유사도를
  Gemini로 계산한다.
- `FR-ORCHESTRATE`: 증거 추출, 콘텐츠 채점, 썸네일 비교를 전역 순차 단계로 실행하며 각 단계
  동시량은 `GEMINI_JUDGE_CONCURRENCY`를 넘지 않는다.
- `FR-RESULT`: 분석 불가 우선, 합산 위험도 내림차순으로 큰 카드 목록을 표시한다.
- `FR-REASON`: 여섯 축 기여도 중 큰 두 개를 사용해 상세 펼침 없이 한 줄 이유만 표시한다.
- `FR-UNSUBSCRIBE`: 자동 선택·자동 해제를 금지하고 최종 확인 뒤 선택 항목만 삭제한다.

## 점수 계약

- 콘텐츠: 출처 불명확 30 + 치료·복약 변경 유도 10 + 구매 유도 10 = 50.
- 채널 콘텐츠 집계: `round(최고 영상 × 0.5 + 성공 영상 평균 × 0.5)`.
- 공장형: 업로드 속도·규칙성 10 + 합성 공개 표시 10 + 썸네일 유사도 30 = 50.
  기존 측정 방식은 유지하고 업로드 30점 원점수는 3으로 나눠 반올림하며, 썸네일 0..10
  유사도는 3배한다.
- 합산: 콘텐츠 + 공장형 = 0..100. 0..20 정상, 21..60 경고, 61..100 위험.

## 비기능 요구사항

- 시니어 사용자가 확대 없이 읽을 수 있는 큰 글자, 48px 이상의 조작 영역, 명확한 상태 색과
  색 외 텍스트 표기를 제공한다.
- OAuth 토큰과 API 키는 서버에만 두고 모든 외부 응답을 런타임 schema로 검증한다.
- 일시 오류와 형식 오류는 최초 포함 최대 3회 시도하고 실패를 0점으로 바꾸지 않는다.
- 분석 데이터는 `ANALYSIS_TTL_HOURS` 뒤 만료한다.

## 제외 범위

시청 기록, Takeout/Data Portability, 좋아요·싫어요, 추천 제어, 브라우저 자동화, 비공식 자막,
영상 다운로드, 자동 구독 해제, 외부 검색 기반 사실 검증은 제외한다.

## 완료 조건

결정적 점수 경계 단위 테스트, YouTube·Gemini 어댑터 통합 테스트, 전체 단계 상태 전이 테스트,
선택·확인·삭제 E2E가 통과하고 실제 개발 계정에서 결과 카드가 표시되어야 한다.
